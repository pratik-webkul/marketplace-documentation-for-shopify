# User Guide for Customer Order Management

You might be using the [Multi-vendor Marketplace app](/zenith/introduction/overview.html) on your Shopify store. Till now, your customers had no option to manage orders on their own once they purchase any seller's products. Keeping this in mind, we have integrated the [Customer Order Management App](https://webkul.com/blog/shopify-customer-order-management/) in the Multi-vendor Marketplace App.

Now, you can allow sellers to let their customer's manage orders. Sellers, on the other hand, update the order status from their respective seller panels.

You can enable the **Customer Order Management Configuration** tab from the **COM Configuration** & activate the option for customers to manage orders of their respective seller's products.

Thus, customer can easily raise **RMA** (Return, Cancel or Exchange) request, **invoice** request, request the admin to **change their shipping address**, and **reorder** their previous purchase. Accordingly, the status will be updated in the app.

The app is **FREE** of cost but you have to pay for the integration that will cost you **$15 USD/month** over & above your current Multi-vendor App plan.

 Features
----------------
*   Customers can **raise RMA requests** from their "My Account" section.
*   Customers can **request for order Invoice**.
*   Moreover, customers can **reorder their previous purchase** & **get discount benefits**. 
*   Customer can request the admin to **change their shipping address**.

Once your customers are happy with the service you provide, you can easily get your sales rolling.

 How to Enable this Feature App?
-------------
To enable the Customer Order Management feature app, you need to visit the “Featured Apps” section of Multivendor admin panel.

There, You can search for the Customer Order Management Feature App. Once you get this feature, you need to click on the “**Enable**” button to activate this feature in Multivendor app.

You will be asked to [install](https://apps.shopify.com/customer-order-management-by-webkul) the Customer Order Management app to your Shopify store. Install the app to your Shopify store & reflect the features & functionalities on your marketplace.

[![customer Order Management](https://cdnblog.webkul.com/blog/wp-content/uploads/2026/06/com1.webp)](https://cdnblog.webkul.com/blog/wp-content/uploads/2026/06/com1.webp)

Hit the "Enable" button to activate the Feature App.

Now, once you will approve the charge for this app, you will be ended up installing this feature in Multi-vendor app.

## Return Shipping Fee Configuration and Refund Process

This guide explains how to configure Return Shipping settings in the Webkul Multivendor Marketplace (MVM) app and manage the complete return and refund workflow, from the customer's return request to the final refund processing.

It covers return shipping label generation, return shipment handling by the seller, product receipt confirmation, and refund processing by the Admin.

### Step 1: Configure Return Shipping Settings (Admin Panel)

Before processing return requests, the Admin needs to configure the Return Shipping settings.

1. Log in to the **MVM Admin Panel**.
2. Navigate to **Configuration → Order Configuration**.
3. Enable the **Generate Return Shipping Label** option.
4. Configure the following settings:
   - **Who Will Generate Shipping Label:** Specify who will generate the return shipping label.
   - **Label Cost Type:** Select the applicable label cost type.
   - **Charges Apply To:** Specify who will be charged for the return shipping cost.
   - **Label Cost Amount:** Enter the return shipping cost. This amount will be deducted from the customer's refund amount when the refund is processed.
   - **Return Shipping Label Cost Bear By:** Select who will bear the return shipping label cost.
5. Select the return shipping carrier.

   The supported carriers are:
   - Easyship
   - EasyPost
   - Australia Post

Once all the required settings are configured, save the changes.

![Return Shipping Settings](https://cdnblog.webkul.com/blog/wp-content/uploads/2026/11/comsone.webp)

### Step 2: Customer Places an Order

1. The customer places an order on the Shopify store.
2. Once the order is delivered, the customer can request a return if they wish to return the purchased product.

### Step 3: Customer Submits a Return Request

To submit a return request, the customer needs to:

1. Log in to their customer account.
2. Navigate to **My Account → My Orders**.
3. Open the delivered order they wish to return.
4. Click the **Return** option.
5. Submit the return request with the required details.

![Customer Return Request](https://cdnblog.webkul.com/blog/wp-content/uploads/2026/11/comss.webp)

Once submitted, the return request will be available in the Admin Panel for review.

### Step 4: Admin Approves the Return Request and Generates the Return Shipping Label

The Admin can review and process the customer's return request from the MVM Admin Panel.

1. Log in to the **Multivendor Marketplace Admin Panel**.
2. Navigate to **Orders → Return Request**.
3. Open the customer's return request.
4. Review the return request details and accept the request.
5. Proceed to fulfill the return request.
6. Select the configured return shipping carrier, such as **EasyPost**.
7. Fetch the available shipping rates and select the appropriate rate.
8. Complete the fulfillment process.

![Review Return Request](https://cdnblog.webkul.com/blog/wp-content/uploads/2026/11/comstwo.webp)

![Select Return Shipping Carrier](https://cdnblog.webkul.com/blog/wp-content/uploads/2026/11/comsthree.webp)

![Generate Return Shipping Label](https://cdnblog.webkul.com/blog/wp-content/uploads/2026/11/comsfour.webp)

Once the fulfillment is completed, the return shipping label will be generated, and the customer will receive the label via email.

### Step 5: Customer Ships the Product Back to the Seller

1. The customer receives the return shipping label via email.
2. The customer downloads and prints the label.
3. The customer attaches the label to the return package.
4. The customer uses the provided label to ship the product back to the respective seller.

![Return Shipping Label](https://cdnblog.webkul.com/blog/wp-content/uploads/2026/11/comsss.webp)

### Step 6: Seller Receives the Returned Product

Once the returned product reaches the seller, the seller needs to confirm its receipt.

1. The seller logs in to the **Seller Panel**.
2. Navigates to **Orders → Return Request**.
3. Opens the relevant return request.
4. Reviews the return details.
5. Clicks **Mark as Received** to confirm that the returned product has been received.

Once the seller marks the product as received, the updated return status will be reflected in the Admin Panel. This allows the Admin to know that the seller has received the returned product.

![Seller Marks Returned Product as Received](https://cdnblog.webkul.com/blog/wp-content/uploads/2026/11/comsfive.webp)

### Step 7: Admin Processes the Refund

After the seller confirms receipt of the returned product, the Admin can proceed with the refund.

1. Log in to the **Multivendor Marketplace Admin Panel**.
2. Navigate to **Orders → Return Request**.
3. Open the relevant return request.
4. Verify that the seller has marked the returned product as received.
5. Click **Process Refund** to initiate the refund.

The system will calculate the applicable return shipping label cost and deduct it from the customer's refundable amount.

The Admin can review the adjusted refund amount before processing the refund.

![Review and Process Refund](https://cdnblog.webkul.com/blog/wp-content/uploads/2026/11/comssix.webp)

### Step 8: Automatic Refund and Seller Earning Adjustment

Once the Admin processes the refund:

- The refund is updated in Shopify automatically.
- The Admin does not need to process the same refund separately from the Shopify Admin Panel.
- The applicable return shipping label cost is deducted from the customer's refund amount.
- The refunded amount is adjusted against the respective seller's earnings.

This completes the return and refund process.

### Complete Return and Refund Workflow

The complete workflow is as follows:

**Admin Configuration → Customer Places Order → Customer Submits Return Request → Admin Approves Request → Admin Generates Return Shipping Label → Customer Ships Product → Seller Receives Product → Seller Marks as Received → Admin Processes Refund → Shopify Refund Update and Seller Earning Adjustment**
