# Influencer Marketplace: A Powerful Add-on for Multivendor Marketplace

The **Influencer Marketplace** is an advanced feature app designed to connect sellers with influencers, enabling collaboration to boost product sales through influencer marketing.

This guide covers the complete workflow, including **installation, configuration, and usage** from **Admin, Seller, and Influencer perspectives**.

![Influencer Marketplace Overview](https://cdnblog.webkul.com/blog/wp-content/uploads/2026/04/influencermarketplaceone.webp)


 Installation Process & Overview
-----------------
To begin using the Influencer Marketplace, install the app:

![Installation Process](https://cdnblog.webkul.com/blog/wp-content/uploads/2026/04/influencermarketplacetwo.webp)

- Navigate to the **Multivendor Marketplace App**
- Go to the **Featured Apps** section
- Under **Marketplace Other Add-ons**, locate **Influencer Marketplace**
- The app is available at a cost of **$10/month**
- Click on **Install** to activate the feature

This app allows sellers to:
- Hire influencers
- Track commissions
- Manage influencer-based promotions


 Login Process
--------------
There is **no separate login required** for influencers or sellers.

![Login Process](https://cdnblog.webkul.com/blog/wp-content/uploads/2026/04/influencermarketplacethree.webp)

- Users can log in through the **same panel used by sellers**
- After installation, a new option called **“Influencer”** appears in the dropdown menu
- This option is visible only after installation


 Admin Panel Configuration
-----------------
The admin manages and controls the influencer marketplace setup.

### Influencer Marketplace Configuration

#### a. Allow Influencers to Self-Register

- Enable this option to allow users to sign up as influencers

![Self Register](https://cdnblog.webkul.com/blog/wp-content/uploads/2026/04/influencermarketplacefour.webp)

![Self Register Form](https://cdnblog.webkul.com/blog/wp-content/uploads/2026/04/influencermarketplacefive.webp)

#### b. Allow Seller to Set Commission Rate

- Sellers can define custom commission rates for each influencer

![Commission Setting](https://cdnblog.webkul.com/blog/wp-content/uploads/2026/04/influencermarketplacesix.webp)

#### c. Commission Bear By

- Currently, only the **Seller** option is available  
- The seller bears the influencer commission cost

#### d. Deduct Influencer Commission On Order Refund

![Refund Deduction](https://cdnblog.webkul.com/blog/wp-content/uploads/2026/04/influencermarketplaceseven.webp)

- If enabled, influencer commission is deducted when an order is refunded

 Seller Panel Workflow
------------
### Hiring an Influencer

- Navigate to **Influencer Marketplace → Influencers**
- View the list of available influencers
- Click on **three dots (⋮)** → Select **Hire**

![Hire Influencer](https://cdnblog.webkul.com/blog/wp-content/uploads/2026/04/influencermarketplacefifteen.webp)

- Set the commission rate while sending the request

![Set Commission](https://cdnblog.webkul.com/blog/wp-content/uploads/2026/04/influencermarketplaceeighteen.webp)


### Managing Influencers

Sellers can:

- Cancel hiring requests

![Cancel Request](https://cdnblog.webkul.com/blog/wp-content/uploads/2026/04/influencermarketplacenineteen.webp)

- Terminate hired influencers

![Terminate Influencer](https://cdnblog.webkul.com/blog/wp-content/uploads/2026/04/influencermarketplacesixteen.webp)


### Viewing Influencer Details

Sellers can view:

![Influencer Details](https://cdnblog.webkul.com/blog/wp-content/uploads/2026/04/influencermarketplacefourteen.webp)

### Payments to Influencers

![Payments](https://cdnblog.webkul.com/blog/wp-content/uploads/2026/04/influencermarketplacetwenty.webp)

### Order-Based Commission Management

![Order Commission](https://cdnblog.webkul.com/blog/wp-content/uploads/2026/04/orderview.webp)

- Go to **Order Listing**
- View **Influencer Earnings**
- Accept or reject commission per order

**Note:** This option is available only after the order is **fulfilled**.
