**[Multivendor Marketplace for Shopify](/zenith/introduction/) | Order Prepare Status Feature**  
With this feature, the seller can intimate admin about the status of the order step by step.

When the order is placed & received then admin & seller can mark the order prepare status on various stages.

 Stage-1
-----------
To enable this feature, visit the Configuration >>> Order configuration >>> and enable Order status from there.  

![order](https://cdnblog.webkul.com/blog/wp-content/uploads/2018/01/Screenshot_2.png)

 Stage-2
-----------
Once an order is placed, the shipping status will set to "collect" at the seller side and "busy " at the admin side.

![vendor](https://cdnblog.webkul.com/blog/wp-content/uploads/2018/01/Orders-Admin.png)

 Stage-3
------------
Now the seller will click the "collect" button for a corresponding order to notify the admin to collect the product. Here admin will receive an email regarding the same.

Now at the admin side, the shipping status of that order is in the "Collect" state and at the seller side, it's "Pending".

![collect](https://cdnblog.webkul.com/blog/wp-content/uploads/2018/01/22.png)

 Stage-4
-------------
Once admin clicks the "collect" button for an order, the status changes to "collecting" at both sides.

![order status](https://cdnblog.webkul.com/blog/wp-content/uploads/2019/09/Screenshot-51.png)

 Stage-5
----------------
![order status](https://cdnblog.webkul.com/blog/wp-content/uploads/2018/01/Screenshot_1.png)

Now the admin collects the product, to notify the seller he clicks the collecting button. Here the status changes to "collected" at both sides.

NOTE:  In case, the seller is unable to collect the order in the mentioned time interval, then the order gets expired, then, in this case, the order gets refunded.
